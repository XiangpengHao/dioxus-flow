We'd like to create a dioxus framework similar to react-flow, called dioxus-flow.

1. use nix flake to manage dev dependencies
2. the framework should functionally very similar to react-flow, but using dioxus instead of react
3. use idomatic dioxus primitives.
4. be high performance and efficient.
5. Include auto layout capabilities.
6. add animations, transitions.
7. include a way to customize the nodes and edges.
